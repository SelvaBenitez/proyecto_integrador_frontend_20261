# Proyecto Integrador Fase I
## Inicio de Sesión en JavaScript

## Descripción:
Este proyecto implementa un proceso básico de inicio de sesión utilizando lógica en JavaScript, estructuras condicionales, ciclos y variables.

El sistema permite:
• Solicitar al usuario el ingreso del nombre de usuario y la contraseña.
• Leer e imprimir los datos por consola.
• Verificar mediante condicionales si las credenciales son correctas.
• Permitir el acceso cuando los datos sean válidos.
• Indicar cuando los datos sean incorrectos.
• Utilizar un ciclo para controlar los intentos de acceso.
• Mostrar un mensaje de bloqueo cuando se superen tres intentos fallidos.

## Cómo se debe usar:
1. Clonar el repositorio: 
2. Abrir la carpeta del proyecto.
3. Ejecutar el archivo `index.html` en el navegador.
4. Seguir los pasos que aparecen en pantalla:
• Crear usuario
• Crear contraseña
• Intentar iniciar sesión: Si las credenciales coinciden, se muestra un mensaje de acceso exitoso. Si las credenciales son incorrectas, se muestra una alerta. Tienes tres intentos disponibles para acceder al sistema. Si el usuario y/o contraseña son incorrectos las tres veces, la cuenta se bloquea.
