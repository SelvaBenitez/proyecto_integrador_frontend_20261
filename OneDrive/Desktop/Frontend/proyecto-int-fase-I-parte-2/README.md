# 🎓 SMART Language Academy — Proyecto Integrador Fase I, Parte 2

> Proyecto universitario de desarrollo web para una academia de idiomas ficticia llamada **SMART**.  
> El objetivo es simular la venta de un nuevo software a dicho negocio, construyendo una aplicación web funcional y visualmente presentable.

---

## 📌 Contexto del proyecto

Este repositorio es la **continuación de la Fase I — Parte 1**, desarrollada en el semestre anterior, donde se estableció la estructura base en HTML y los estilos visuales en CSS.

En esta segunda parte (**Parte 2**), el enfoque está en **pulir la lógica del proyecto mediante JavaScript**, conectando los elementos de la interfaz con comportamientos dinámicos e interactivos.

---

## 🗂️ Estructura del proyecto

```
proyecto-int-fase-i-parte-2/
│
├── css/
│   ├── normalize.css        # Reset de estilos para consistencia entre navegadores
│   └── styles.css           # Estilos personalizados del proyecto
│
├── html/
│   ├── bienvenida.html      # Página principal / landing de bienvenida
│   ├── inicio-sesion.html   # Formulario de inicio de sesión
│   └── registro.html        # Formulario de registro de nuevos usuarios
│
├── imagenes/
│   ├── estudiar.png         # Imagen de apoyo visual para la interfaz
│   └── favicon.png          # Ícono de la pestaña del navegador (logo SMART)
│
└── logica-proyecto.js       # Lógica principal en JavaScript (validaciones, interacciones, flujo de usuario)
```

---

## 🧠 ¿Por qué el logo de SMART?

El logo de **SMART** se utiliza porque el proyecto simula ser el desarrollo de software a la medida para una academia de idiomas con ese nombre. La marca visual (logo como favicon e imagen de interfaz) forma parte de la propuesta comercial: se busca que el cliente —la academia— vea reflejada su identidad en el producto, haciendo la demo más convincente y profesional.

---

## 🛠️ Tecnologías utilizadas

- **HTML5** — Estructura semántica de las vistas
- **CSS3** — Estilos y diseño visual (`normalize.css` + `styles.css`)
- **JavaScript (Vanilla)** — Lógica del proyecto: validaciones de formularios, manejo de eventos y flujo de navegación
